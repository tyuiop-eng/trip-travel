# Задачи для Issues — команда 2

Каждая задача — отдельная ветка `feature/<номер>-<краткое-название>` и отдельный PR в develop.
В тексте Issue: что сделать, кто отвечает, критерий готовности, как проверить.

---

### #1 Создание поездки с проверками — Лапатинский
**Что сделать.** Пункт меню «Создать поездку» и метод добавления в хранилище: непустые название и место назначения, уникальный номер, положительный целый бюджет; даты существуют в календаре, окончание не раньше начала (проверка дат — `validate_dates` в `src/validation.py`).
**Готово, когда.** Ошибочный ввод не создаёт частичную запись; корректная поездка видна в списке.
**Как проверить.** Модульные тесты: пустые поля; бюджет 0, −5, «abc»; дата 2026-02-30; окончание раньше начала.

### #2 Меню и поиск поездки по номеру — Лапатинский
**Что сделать.** Консольное меню (создать, список, поиск, расход, отчёт) с обработкой неверного ввода; поиск по номеру; для неизвестного номера — сообщение, после которого работа продолжается.
**Готово, когда.** Любой неверный ввод меню не приводит к падению программы.
**Как проверить.** Ввод букв вместо номера, пустой ввод, несуществующий номер, выход и повторный вход.

### #3 Добавление расхода с проверками — Ларин
**Что сделать.** Расход добавляется только к существующей поездке; категория из списка «транспорт», «жильё», «питание», «другое»; сумма — положительное целое. Неверная категория или сумма не меняют сохранённые данные.
**Готово, когда.** Проверки расположены в `src/validation.py` и переиспользуются импортом.
**Как проверить.** Модульные тесты на каждую категорию, сумму 0 и −1, неизвестную поездку.

### #4 Расчёт бюджета и превышение — Ларин
**Что сделать.** Для каждой поездки: общая сумма расходов и остаток. Превышение разрешено: расход сохраняется, остаток отрицательный, программа показывает сумму превышения. Без расходов сумма равна нулю.
**Готово, когда.** Функция расчёта не зависит от меню и вывода.
**Как проверить.** Тесты: без расходов; в точную сумму; с превышением; расходы в нескольких категориях.

### #5 Отчёт по поездке и сортировка списка — Радыгин
**Что сделать.** Отчёт: даты, длительность в календарных днях включительно, бюджет, расходы всего и по категориям, остаток либо превышение. Список поездок сортируется по дате начала, при равенстве — по номеру.
**Готово, когда.** Длительность для поездки «10.11–14.11» равна 5 дням; сортировка подтверждена тестом на равных датах.
**Как проверить.** Тест на длительность включительно; тест сортировки с одинаковыми датами начала.

### #6 Импорт расходов из CSV — Радыгин
**Что сделать.** Атомарный импорт: при любой ошибке отклоняется весь файл; отчёт содержит номер строки и причину каждой ошибки, при неверных заголовках — причину отказа файла. Номера уникальны внутри файла и среди сохранённых; проверки категории и суммы — те же, что при ручном вводе.
**Готово, когда.** Корректный файл сохраняется целиком с отчётом о числе добавленных; частичных добавлений нет.
**Как проверить.** Файлы `data/expenses_example.csv` (успех) и `data/expenses_bad.csv` (отказ целиком); файл с неверными заголовками; дубликат номера; расход к несуществующей поездке.

### #7 Фильтр истории расходов — Лапатинский
**Что сделать.** Фильтр по номеру поездки и категории; пустой фильтр — любое значение; оба заполненных действуют одновременно. Неизвестный номер и недопустимая категория отклоняются с сообщением. Строки — по номеру расхода; отсутствие совпадений обозначается явно.
**Готово, когда.** Фильтры не меняют общий бюджет и сохранённые записи.
**Как проверить.** Комбинации: только поездка, только категория, обе, обе пустые; несуществующая поездка; категория «еда».

### #8 Выгрузка истории в XLSX — Радыгин
**Что сделать.** Выгрузка текущей отфильтрованной истории: лист «Данные» (все поля выбранных расходов), лист «Итоги» (суммы по четырём категориям и общий итог только выбранных строк). Порядок совпадает с экранным; суммы — числами. Пустая выборка — заголовки и нулевые итоги.
**Готово, когда.** Исходные данные не меняются; существующий файл перезаписывается только после подтверждения (после задачи #10).
**Как проверить.** Открыть файл и сверить с экранным списком; выгрузка пустой выборки.
